# KROSS KOREA 🇰🇷

Koreyadan original krossovkalar — Telegram Mini App va bot.

## Loyiha haqida

Telegram ichida ishlaydigan do'kon: mijoz krossovkani tanlaydi, savatga soladi va
buyurtma beradi. Admin buyurtmalarni bot va admin panel orqali boshqaradi.

## Tuzilma (rejada)

```
kross_korea/
├── backend/    Node.js — Telegram bot va API (PostgreSQL / Neon)
└── frontend/   Next.js — Telegram Mini App
```

## Texnologiyalar

- **Backend:** Node.js, Telegram bot, PostgreSQL (Neon)
- **Frontend:** Next.js (App Router), TypeScript, Zustand
- **Deploy:** Vercel (frontend), Neon (baza)
